ImageSmith

Customize Linux disk images from a declarative recipe — natively on your Mac.

Download for macOS
Requires macOS 26 on Apple silicon · Source on GitHub

Declarative recipes

Describe packages, files, users and services once; rebuild the same image every time.

Native builds

Images are built in a lightweight Linux container — no VM to manage.

Built-in assistant

Ask the assistant to edit your recipe, explain build output, or fix failures.

Files & terminal

Browse the image filesystem and open a shell inside it before you ship.

Flash to disk

Write the finished image straight to an SD card or USB drive.

CLI included

The imagesmith command line tool ships inside the app for scripting and CI.

First launch

The app is not notarized yet. If macOS says it can't be opened, right-click ImageSmith in Applications and choose Open, or run:

xattr -dr com.apple.quarantine /Applications/ImageSmith.app
